## 一个人买全家享？小算盘背后的技术卡点

许多用户在挑选套餐时，想着‘买一个大流量套餐，把订阅发给父母、室友和多台手机电脑一起用’。然而没过多久，就发现某台设备突然连不上，或者面板直接提示‘超过最大同时在线限制，账号临时冻结 1 小时’。

机场为了防止单账号被无限转卖（号贩子滥用），普遍设置了严格的设备管控机制。不同机场的管控维度大相径庭，如果不搞清楚规则，家庭合租极易变成‘抢网大战’。

---

## 两大约束模式：同时在线 IP 数 vs 并发连接数 (Connections)

1. **同时在线 IP 限制 (Max Online IPs)**：最普遍的限制模式。系统只统计客户端发起连接时的**公网 IP 数量**。只要同一家庭在同一个 Wi-Fi（局域网）下，所有设备对外展示的都是同一个公网 IP，因此只算作 1 个设备；但只要有人出门切换为 5G 蜂窝网络，就会立即占用第 2 个公网 IP；

2. **并发连接数限制 (Max Concurrent Connections)**：较为严苛的底层限制。限制同时活跃的 TCP/UDP 会话数。一台电脑多开网页或下载时就可能产生数百个并发，极易触顶导致其他设备掉线。

### 主流多设备限制机制与合租可行性评估

| 限制类型 | 典型规格限制 | 家庭同 Wi-Fi 表现 | 多地异地合租表现 | 软路由突破能力 |
| :--- | :--- | :--- | :--- | :--- |
| 同时在线 IP 限制 | 通常限制 2~5 个 IP | 完美兼容 (整屋全设备计为 1 个 IP) | 严格受限 (不得超过规定外网 IP 数) | 天然支持，极佳 |
| 严格客户端绑定 | 限制 3~5 台独立硬件 | 严格受限 (每台手机电脑单独计入) | 严格受限 | 需配置软路由虚拟网关代理 |
| 并发连接数限制 | 限制 300~500 个并发 | 一般 (下载时容易撑爆并发数) | 极差 (多人同时看视频容易卡死) | 无法通过路由突破并发物理限制 |
| 不限设备模式 | 仅限制总带宽速率 | 最理想合租模式 | 最理想合租模式 | 完全无阻碍 |

## 利用家庭旁路由/软路由实现单 IP 全屋共享

### 生产级配置与实操代码

```yaml
# OpenWrt / iStoreOS 旁路由全局透明网关配置思想
# 全屋电视、手机、iPad 网关指向软路由 IP (如 192.168.1.2)
# 对机场网关而言，永远只表现为软路由一个设备单一连接！

network:
  lan:
    ipaddr: 192.168.1.2
    gateway: 192.168.1.1 # 主光猫/主路由 IP
    dns: 192.168.1.2     # 由旁路由接管 DNS 解析

# 开启 Clash Verge / OpenClash 的 Fake-IP 模式
# 轻松承载全家 15+ 智能家居与移动设备，永不触碰机场设备上限
```

#### 核心实施要点
1. **家庭同住场景配置旁路由**：将代理客户端安装在常开的软路由或电视盒子上，局域网全员共享单一出口 IP。
2. **异地合租核对 IP 限制配额**：若与外地朋友合租，务必购买明确标注‘支持 5 个以上异地 IP’的定制合租套餐。
3. **定期清理闲置设备会话**：在机场官网后台找到‘在线设备管理’，一键踢出早已弃用的老旧平板或备用机。

## 合租场景典型冲突化解


### 场景 1：室友一开下载，其他人所有网页全部打不开
- **底层原因剖析**：单人占满了机场分配给该账号的最大并发连接数或跑满了单账号限速峰值。
- **针对性解决对策**：在局域网主路由开启 SQM（智能队列管理），对每台内网设备施加公平带宽调度。


### 场景 2：手机在外开热点导致家中所有智能电视节点断连
- **底层原因剖析**：触发了‘最大 2 个 IP’限制，外网新 IP 连接导致服务端强制踢掉了家中的旧连接。
- **针对性解决对策**：升级至更高配额套餐，或在外使用另一套备用小流量机场。

## 科学规划共享架构

1. **善用家庭网关统一分流**：软路由透明代理不仅体验无感，更是规避多设备限制的最优工程解法。

2. **明晰权责避免合租纠纷**：合租前约定好流量消耗比例与用途，杜绝一人 BT 刷流全员断网的尴尬。
