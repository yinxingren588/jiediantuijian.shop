## 为什么 Windows 平台首选 Clash Verge Rev？

在 Windows 10 与 Windows 11 环境下，早期的 Clash for Windows 已于数年前停止维护。当前社区最受好评、维护最活跃的客户端是 **Clash Verge Rev** 与 **Sing-box**。

Clash Verge Rev 具备以下核心优势：
- 内置基于 Clash Meta（Mihomo）内核，原生支持现代协议（VLESS、Hysteria2、TUIC、Trojan、Shadowsocks 等）。
- 拥有现代化的 UI 界面，支持深色模式与中文语言。
- **一键开启 TUN 模式**，无需配置复杂的系统代理或局域网转发，即可接管游戏、命令提示符（CMD/PowerShell）、Docker 等所有软件的网络流量。
- 内存占用低，后台运行稳定，无捆绑广告。

---

## 步骤一：准备工作与下载客户端

1. **获取机场订阅链接**：登录你在本站推荐选购的机场后台（如 [隐形人](/airport/yinxingren/) 或 [微风网络](/airport/breezenet/)），在用户仪表盘找到“快捷导入”或“复制订阅链接（Clash/Meta）”。
2. **下载客户端安装包**：前往官方 GitHub Releases 页面下载 `Clash.Verge_x.x.x_x64-setup.exe`。
3. **完成安装**：双击安装包，建议默认安装路径。首次打开时，若 Windows Defender 提示防火墙拦截，请务必勾选“专用网络”和“公用网络”并点击“允许访问”。

---

## 步骤二：导入节点订阅链接

1. 打开 Clash Verge Rev 客户端主界面。
2. 点击左侧导航栏的 **“订阅” (Profiles)** 菜单。
3. 在顶部输入框粘贴你从机场后台复制的订阅 URL 地址。
4. 点击 **“保存” (Save)** 或 **“下载” (Download)** 按钮。
5. 客户端将自动拉取远程配置与节点列表。下载成功后，右键或单选该配置卡片，将其设为“激活”状态（显示蓝色对勾或高亮标记）。

> **常见问题排查**：如果下载订阅时提示网络超时或解析失败，请检查本机 DNS 是否被劫持，或尝试先开启本地热点进行首次更新。

---

## 步骤三：出站模式选择（规则分流 vs 全局代理）

在主界面左侧点击 **“代理” (Proxies)**：

- **规则模式 (Rule)**【强烈推荐】：客户端会根据内置的分流规则自动判断目标网站。国内网站（如百度、淘宝、Bilibili、知乎等）走本地直连，完全不消耗机场流量且网速最快；国外网站（如 Google、YouTube、GitHub、ChatGPT 等）自动通过代理节点访问。
- **全局模式 (Global)**：所有网络请求全部强行通过指定节点中转。一般仅用于排查特定冷门海外网站无法访问时使用。
- **直连模式 (Direct)**：所有流量直接连接目标服务器，不走任何代理。

建议日常使用一律保持 **“规则模式”**。

---

## 步骤四：开启系统代理与 TUN 虚拟网卡模式

1. 点击左侧 **“设置” (Settings)**。
2. 找到 **“系统代理” (System Proxy)** 开关并打开，此时浏览器等常规软件即可顺畅上网。
3. **进阶设置：启用 TUN 模式**：
   - 首次开启 TUN 模式前，需要安装虚拟网卡服务（Service Mode）。点击界面中的“服务模式”旁边的“安装”按钮，按照系统 UAC 提示授权管理员权限。
   - 安装完成后，打开 **“TUN 模式”** 开关。
   - 开启 TUN 后，CMD/Git 终端、Telegram 桌面版以及外服游戏将自动被接管，彻底解决终端无法走代理的历史痛点。

---

## 步骤五：防范本地时间偏差导致的握手失败

许多用户反馈“节点延迟测试都正常，但浏览器就是打不开网页”，90% 的原因在于 **Windows 本地时间偏差**。

由于现代加密协议（如 VMess、Trojan 等）采用了基于时间戳的防重放攻击验证机制，若本机时间与标准北京时间偏差超过 **60 秒**，服务器端将直接丢弃所有握手数据包。

**解决办法**：
- 按下快捷键 `Win + I` 打开 Windows 设置。
- 进入“时间和语言” → “日期和时间”。
- 点击“立即同步”按钮，确保“自动设置时间”处于开启状态。
