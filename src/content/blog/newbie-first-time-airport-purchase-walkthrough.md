## 核心概念极简拆解：搞懂“机场”与“客户端”的关系

新手最容易混淆的误区，是以为买了机场就拥有了一个可以点击打开的软件。记住这个通俗的比喻：

**客户端（如 Clash Verge Rev、v2rayN、Shadowrocket）就像是一辆空车**，它是免费、开源的软件载体；**机场就像是加油站**，它为你提供驱动小车出海的**汽油（节点与订阅链接）**。你必须先在电脑或手机上下载好小车，然后将加油站给你的那串‘订阅链接’放进小车里，小车才能跑起来！

## 全流程保姆级四步实操指南

### 生产级配置与实操代码

```bash
# 订阅链接的标准格式示例 (请勿泄露给他人)
https://airport-sub-domain.com/api/v1/client/subscribe?token=a1b2c3d4e5f6g7h8

# 导入步骤：
# 1. 在客户端点击 "配置 (Profiles)"
# 2. 粘贴上述 URL，点击 "下载/导入 (Download)"
# 3. 切换至 "代理 (Proxies)" 页面选择节点，开启 "系统代理 (System Proxy)"
```

#### 核心实施要点
1. **选择正规靠谱机场并注册**：进入本站严选推荐的机场官网，使用常用邮箱完成注册，设置独立强密码。
2. **选购月付轻量入门套餐**：纯新手第一月强烈建议选择 15~25 元左右的月付小流量套餐，支持支付宝扫码结算。
3. **一键复制订阅链接**：在个人用户后台仪表盘，找到‘快捷导入’或‘一键订阅’，点击‘复制通用订阅链接’。
4. **在客户端中粘贴并启动代理**：打开预先安装好的客户端，粘贴链接导入节点列表，选中一个‘香港’或‘日本’节点，打开‘系统代理’开关即可！

## 新手第一次使用最容易卡住的地方


### 场景 1：订阅链接粘贴进去后，提示‘网络错误 / Download Failed’
- **底层原因剖析**：由于本地尚未翻墙，直连机场的订阅服务器遭遇了本地运营商网络阻断。
- **针对性解决对策**：使用手机流量开热点给电脑重试，或向客服索取免翻墙订阅专用解析短链接。


### 场景 2：节点列表显示全绿延时，但浏览器依然打不开 Google
- **底层原因剖析**：只导入了节点，未在客户端左下角打开‘系统代理 (System Proxy)’或‘TUN 模式’总开关。
- **针对性解决对策**：确保客户端界面上的‘系统代理’滑块已拨动至开启状态（显示绿色）。
