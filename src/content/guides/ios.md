## iOS 平台的特殊性与必备条件

由于苹果 App Store 的区域政策限制，中国大陆区（国区）App Store 无法直接上架和下载任何代理网络客户端。

因此，要在 iPhone 或 iPad 上配置机场节点，必须满足以下前置条件：

1. **拥有一个非国区 Apple ID**：通常为美区（United States）、港区（Hong Kong）或台区 Apple ID。
2. **下载正版网络客户端**：其中最流行、性价比最高的是 **Shadowrocket（小火箭）**（美区售价 2.99 美元，一次性购买永久使用）。部分成熟机场也会在后台向年付会员免费提供共享美区 ID 辅助下载。

---

## 步骤一：切换非国区 Apple ID 并下载小火箭

> **安全警示**：切换外区 Apple ID 时，**切勿在 iPhone 系统的“设置”主菜单顶部登录 iCloud**，否则可能导致手机被他人远程锁机！务必只在 **App Store** 应用内单独切换登录。

1. 打开桌面上的 **App Store** 应用。
2. 点击右上角个人头像进入账户页面，滑到最底部点击 **“退出登录” (Sign Out)**。
3. 输入你的美区 Apple ID 账号与密码完成登录。
4. 搜索 `Shadowrocket`，认准开发者为 `PanGu Technology` 的正版软件（白色小火箭图标）。
5. 完成下载安装后，即可退出外区账号并换回你的国区主账号。已安装的小火箭仍可正常使用。

---

## 步骤二：向 Shadowrocket 导入节点订阅

1. 打开已购买并订阅的机场后台，找到“一键导入 Shadowrocket”或直接“复制订阅链接”。
2. 打开 Shadowrocket 客户端：
   - 如果系统剪贴板已复制订阅链接，小火箭通常会自动弹窗提示“检测到节点链接，是否添加”，点击“确定”即可。
   - 若未自动弹窗，点击右上角 **“+”** 加号。
   - 类型选择 **“Subscribe” (订阅)**。
   - 在“URL”栏粘贴刚才复制的机场订阅链接，备注栏填写机场名称。
   - 点击右上角“保存” (Save)。
3. 小火箭会自动从云端解析并列出所有可用节点（包含香港、日本、新加坡、美国等）。

---

## 步骤三：启动连接与全局路由设置

1. 在节点列表中，轻触选中你想要连接的节点（选中的节点前方会显示小圆点）。
2. 在首页下方找到 **“全局路由”**，强烈建议勾选为 **“配置” (Config)**：
   - “配置”模式对应规则分流：国内流量直连，海外流量自动代理。
   - 切勿随意切换为“代理 (Proxy)”模式，否则访问微信或外卖软件会导致定位混乱并白白浪费机场流量。
3. 滑动顶部的 **“未连接” 开关** 打开连接。
4. 首次启动时，iOS 系统会弹出“Shadowrocket 尝试添加 VPN 配置”的安全授权窗口，点击“允许”并通过 Face ID / Touch ID 或锁屏密码确认授权。

## 进阶技巧：延迟测试与节点定时自动更新

- **一键测速**：在首页点击“连通性测试”，小火箭会并发向各节点发送轻量 ping 测试，列表中会显示具体毫秒数（绿色数字表示延迟较低）。
- **打开自动更新**：进入小火箭底部“设置” → “订阅” → 打开 **“打开应用时更新”**。这样每次启动小火箭时都会自动同步机场最新的节点 IP 和域名，防止节点失效。
