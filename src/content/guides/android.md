## Android 安卓客户端怎么选？

在开源生态丰富的安卓系统上，目前主流用户使用最多的两款工具是 **Clash Meta for Android** 和 **v2rayNG**：

1. **Clash Meta for Android (CMFA)**：
   - 最适合拥有机场订阅链接的用户。
   - 具有极其强大的国内/国外自动分流规则，微信、抖音、支付宝完全不受任何影响。
   - 界面直观，支持延迟批量测试与节点分组（如流媒体分组、AI专用分组）。

2. **v2rayNG**：
   - 极简直接，不仅支持完整的机场批量订阅，还支持直接扫描二维码或粘贴单个 `vmess://`、`vless://`、`ss://` 链接。
   - 针对国内特定品牌手机（如小米 HyperOS、华为鸿蒙、vivo OriginOS）的后台保活更友好。

## 方案一：Clash Meta for Android 配置实操

### 1. 下载与安装
前往开源社区或在机场用户中心下载最新版 APK 安装包并完成安装。建议避开第三方未知应用商店的二次打包版本。

### 2. 导入配置订阅
- 登录机场后台，点击“一键导入 Clash 订阅”或复制订阅 URL。
- 打开 Clash Meta for Android，点击 **“配置” (Configuration)**。
- 点击右上角的 **“+”** 加号，选择 **“从 URL 导入”**。
- 在“URL”栏粘贴订阅地址，在“名称”栏输入机场名称（如“飞天云”），点击右上角软盘图标保存。
- 返回配置列表，点击刚才添加的配置卡片，当左侧圆圈变为绿色即表示已激活。

### 3. 启动连接与授权
- 回到客户端主页面，点击中央的 **“启动”** 大开关。
- 系统会弹出“网络连接请求”提示窗口，点击“确定”或“允许”创建本地 VPN 隧道。
- 进入“代理”页面，点击右下角雷电图标测速，选择低延迟节点（如香港或日本节点）。

## 方案二：国内安卓手机系统的后台保活技巧

国内手机厂商的深度定制系统（如小米澎湃、OPPO ColorOS、vivo OriginOS、华为 HarmonyOS）普遍具备极其激进的后台杀进程机制，经常导致锁屏十几分钟后节点自动断连。

请按以下三步设置系统白名单：

1. **锁定后台任务卡片**：
   在手机多任务界面中，长按或下拉客户端应用卡片，点击“小锁图标”将其锁定。
2. **电池优化设为“无限制”**：
   进入系统设置 → 应用管理 → 找到 Clash Meta 或 v2rayNG → 点击“省电策略 / 电池管理” → 将其调整为 **“无限制”** 或 **“允许后台高耗电”**。
3. **开启应用自启动权限**：
   在权限管理中，允许客户端“开机自启动”和“关联启动”。

## 分流设置与日常流量防漏

很多安卓用户最担心的问题是“刷短视频或下载大文件时误用了机场流量”。

- 在客户端设置中确认运行模式为 **“规则 (Rule)”**。
- 如果需要彻底杜绝某些国内应用经过代理，可开启客户端的 **“应用分流 / 分应用代理 (Split Tunneling)”** 功能：勾选仅允许 Telegram、Chrome、Twitter、YouTube 等特定软件走代理，其余国内应用完全绕过 VPN 隧道。
