## PoE 交易集市 API 架构与查价工具的工作原理

在《流放之路》(Path of Exile) 国际服中，查价宏（如 **Awakened PoE Trade**）是每位老玩家不可或缺的核心辅助工具。

当你按下 `Ctrl + D` 快捷键时，工具的底层工作流程如下：
1. 抓取游戏内存或剪贴板中的装备词缀数据；
2. 构造一个复杂的 JSON 过滤查询体，向 GGG 官方交易 API（`pathofexile.com/api/trade/search`）发起 POST 请求；
3. 获取前几十条挂牌结果并由本地前端渲染在屏幕悬浮窗上。

由于 GGG 实施了极度严格的 **API 速率限制 (Rate Limiting)**，如果所使用的公共节点有大量国内玩家在同时查价，就会导致所有人的请求瞬间撞车并触发 **429 Too Many Requests 冷却锁定**；同时，高时延还会让每次查价等待数秒，严重拖慢刷图节奏。

## 生产级配置与工程落地指南

### Awakened PoE Trade 代理注入与分流规则

```json
# 针对 Awakened PoE Trade 查价工具的网络设置建议：
# 1. 打开 Awakened PoE Trade 设置 (Shift + Space)
# 2. 找到 "Network" (网络) 选项卡
# 3. 勾选 "Use HTTP Proxy" 并填入本地代理端口：
#    Proxy Host: 127.0.0.1
#    Proxy Port: 7890

# Clash / Sing-box 专属查价与集市分流规则：
payload:
  - DOMAIN-SUFFIX,pathofexile.com
  - DOMAIN-SUFFIX,poecdn.com
  - DOMAIN-SUFFIX,poe.ninja
  - DOMAIN-SUFFIX,filterblade.xyz
  - DOMAIN-KEYWORD,pathofexile
```

#### 推荐实施执行路线
1. 在分流软件中将 pathofexile.com 及其全系生态域名划分至独立的低延迟专线策略组
2. 在 Awakened PoE Trade 设置中显式配置 127.0.0.1:7890 本地 HTTP 代理端口
3. 避免使用万人共享的廉价免费节点，优先选用出口 IP 纯净、未被 GGG 重点风控的专线节点
4. 在游戏中测试对某件高价值暗金按 Ctrl + D，确认在 0.5 秒内清晰弹出最新挂牌与物价曲线

## 常见疑难故障排查与实战应对

### 场景 1：查价时弹窗红字报错 'Error: 429 Too Many Requests. Try again in 60 seconds'
- **底层成因分析**：该代理节点的出口 IP 被局域网内其他用户大量高频调用，耗尽了 GGG 的 API 配额。
- **针对性解决方案**：切换为其他冷门专线节点，或静置 60 秒待配对窗口平复后再查。


### 场景 2：按下 Ctrl + D 毫无反应，悬浮窗不出现
- **底层成因分析**：游戏运行在独占全屏模式，阻止了第三方 Electron 悬浮窗口的覆盖渲染。
- **针对性解决方案**：在游戏显示设置中将显示模式更改为 '无边框窗口化 (Borderless Windowed)'。


### 场景 3：poe.ninja 赛季物价大盘页面打不开，一直处于加载中
- **底层成因分析**：poe.ninja 启用了 Cloudflare 人机验证，本地直连解析超时。
- **针对性解决方案**：确保分流规则包含了 poe.ninja 域名，走高速专线即可瞬间完成 Cloudflare 验证通过。
