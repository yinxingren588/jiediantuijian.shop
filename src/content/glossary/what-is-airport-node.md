## 概念起源：“机场”这个词是怎么来的？

在早期的网络代理时代，开发者 `clowwindy` 开源了著名的轻量级加密代理工具 **Shadowsocks**。因为其英文首字母为“SS”，且图标是一只纸飞机，中文互联网社区便形象地将 Shadowsocks 客户端戏称为“**小飞机**”。

随后，网络上开始涌现出一批商业化的团队，他们搭建了分布在全球各地的海量海外服务器，并打包成一个统一的配置列表出售给普通用户。因为有了成千上万架“小飞机”停靠和起飞的地方，这种提供批量节点服务的商业平台便被形象地称为“**机场**”，而每一台提供中转代理的海外服务器就被称为一个“**节点**”。

## 机场节点的核心工作原理

简单来说，机场节点扮演的是一个“可信的中间邮递员”角色。

```text
[ 用户电脑/手机 ] 
       │ 1. 加密数据请求
       ▼
[ 国内入口服务器 (中转机房) ]
       │ 2. 跨境专用隧道 (IEPL/IPLC 或 公网中继)
       ▼
[ 境外落地服务器 (香港/日本/美国) ]
       │ 3. 访问真实目标
       ▼
[ 目标网站: Google / YouTube / ChatGPT ]
```

1. **本地客户端加密**：当你在浏览器输入海外网站网址时，本地客户端（如 Clash 或 Shadowrocket）会截获该数据包，并使用现代对称加密算法对其进行高强度加密。
2. **中转进入跨境专网**：加密后的数据被发送至国内优质机房（入口）。
3. **境外节点落地**：数据通过跨境隧道抵达境外的落地服务器。落地服务器解开包裹，以当地真实的 IP 地址向目标网站（如 Google 或 OpenAI）发起访问。
4. **原路安全返回**：目标网站响应的数据再顺着加密通道返回给你的设备。

## 什么是“订阅链接 (Subscription URL)”？

过去使用单节点时，用户需要手动向客户端输入 IP、端口、密码、加密方式等繁杂参数。一旦某个节点 IP 被封锁，用户就必须手动重新逐个修改。

**订阅链接** 彻底解决了这个问题：
- 它是机场服务器提供给每个付费用户的一个专属私有网址（URL）。
- 客户端只需填入该网址，即可一键下载并自动同步几百个节点的最新 IP、端口与加密参数。
- 当机场后端维护、更换服务器 IP 或增加新地区时，客户端只需点击“更新订阅”，几秒内就能同步最新可用节点。

> **安全警示**：你的订阅链接内包含你个人的账号凭证与流量密钥，请务必妥善保管，切勿在公开论坛或聊天截图泄露，否则他人可以随意盗用你的月度流量。
