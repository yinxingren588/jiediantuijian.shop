## Capcom 跨平台 P2P 怪物同步模型与网络脆弱点

《怪物猎人：荒野》首次在全平台（Steam、PS5、Xbox Series X/S）实现了完全互通的跨平台联机匹配。然而，跨平台协作带来了前所未有的网络复杂度：

游戏在任务中采用**房主承载状态机 (Host-based State)** 与分布式 P2P 协作模式：
- 房主（发起救援或接任务的猎人）承担了怪物动作判定、部位破坏与伤害计算的核心广播任务；
- 其余三名加入的猎人必须同时与房主及 Capcom 中继调度保持全双工通信。

国内玩家与不同平台的队友（例如 PC 连 PS5）联机时，由于各家底层的 NAT 穿透算法不同，一旦某一方的网络出现 3 秒以上的连接停滞，Capcom 引擎为了防止怪物出现“瞬移与无敌假死”，就会直接判定断线，将掉线猎人单方面踢入单机离线模式，极大破坏共斗体验！

#### 推荐实施执行路线
1. 小队成员尽量统一选择地理位置接近的专线节点（如全员选择香港或全员选择东京）
2. 在代理客户端中开启 TUN 虚拟网卡模式，确保卡普空后台进程流量 100% 走代理
3. 网络条件最好、延迟最低的猎人（如具备公网 IP 或千兆 IPLC 专线）作为任务发起房主
4. 避免在晚高峰联机时段使用廉价动态拨号节点，防止因节点 IP 自动漂移导致瞬断

## 常见疑难故障排查与实战应对

### 场景 1：刚进大厅就提示 '与通讯服务器的连接已切断 (50051-MW1)'
- **底层成因分析**：本地网络与 Capcom ID 鉴权服务器之间的 TLS 握手被国内防火墙阻断。
- **针对性解决方案**：将 cid.capcom.com 域名明确加入专线策略组，确保鉴权握手秒过。


### 场景 2：打到怪物残血即将捕获时，另外 3 名队友突然全部拔刀停滞，随后提示变成单人模式
- **底层成因分析**：房主或本地网络的专线发生了瞬时路由重敛，UDP 心跳超时超过 3 秒。
- **针对性解决方案**：选用具备多线 BGP 自动故障容灾的高质量游戏专线，保障狩猎全程零闪断。


### 场景 3：同在一个狩猎小队，但互相搜不到对方的大厅 ID
- **底层成因分析**：双方绑定的 Capcom ID 下载区或 Steam 客户端下载区域跨区过大被隔离在不同大厅中。
- **针对性解决方案**：双方在 Steam 或游戏内将匹配区域同时设置为相同区域（如 Asia）。
